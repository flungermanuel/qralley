# 0003 – Quest-Antworten im Routen-Bundle

Status: Angenommen
Datum: 2026-11-23
Bezug: SPEC §8.3

## Kontext

Offline muss der Spieler sofort Rückmeldung zu seiner Antwort bekommen.

## Entscheidung

Die richtigen Antworten liegen im Bundle. Der Server prüft jede Antwort beim Sync neu und ist maßgeblich.

## Alternativen

Nur Server-Prüfung: Antwort erst nach Sync sichtbar, schlechte Erfahrung im Funkloch. Gehashte Antworten: bei Auswahlfragen wirkungslos.

## Folgen

Antworten sind ausspähbar. Akzeptiert, solange XP kosmetisch sind. Vor Events/Partnerbelohnungen neu entscheiden.
